# 2. ip
- 局域网ip: 不是永久身份证而是当前局域网下的工牌
- 公网ip: 对外的访问地址

# 3. network interface
> ip分配网络接口
> 不要求一台实体机器只有一个ip

```
家里的局域网：192.168.1.x
├── 手机：192.168.1.10
└── 电脑：192.168.1.23
      │
      └── Docker 内部网络：172.17.0.x
          ├── 宿主机接口：172.17.0.1
          └── 容器接口：172.17.0.2
```

```
手机访问 192.168.1.23:8080
          ↓ 电脑转交
容器的   172.17.0.2:80
```
